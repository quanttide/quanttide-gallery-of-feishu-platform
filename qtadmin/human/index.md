# 量潮招聘的飞书流程

量潮招聘的邮件收发、进群与问卷调研都通过飞书完成，发信环节由自动化程序经飞书 CLI 执行。

## 流程

信息流：邮箱（申请）→ 群（沟通）→ 实训基地（初审）→ 公司（复审）。

1. 邮箱（申请）：申请者投递到 `hr@quanttide.com`，申请从邮箱进来；
2. 群（沟通）：申请者点群邀请链接进「量潮实训基地」群，在群里沟通；
3. 实训基地（初审）：在实训基地完成初审；
4. 公司（复审）：初审结果交回公司复审。

## 意图

1. 申请者投递邮件到 `hr@quanttide.com`，公司通过飞书邮箱接收。
2. 公司通过自动化程序与邮件模板，用飞书 CLI 向申请者发送实训邀请邮件，正文附「量潮实训基地」群邀请链接；申请者点链接进群。
