# 量潮招聘的飞书流程

量潮招聘的邮件收发、进群与问卷调研都通过飞书完成，发信环节由自动化程序经飞书 CLI 执行。

## 流程

1. 申请者投递邮件到 `hr@quanttide.com`，公司通过飞书邮箱接收。
2. 公司通过自动化程序与邮件模板，用飞书 CLI 向申请者发送邮件，邮件附「量潮实训基地」群二维码；申请者扫码进群。
3. 申请者加入「量潮实训基地」飞书外部群后，公司发送问卷调研。

## Pipeline 分解

按执行者拆开：系统独走的段落是 pipeline，人接手的段落留在流程里。三条 pipeline 顺序相接，
每条一篇文档：

- [投递发码](./qr_dispatch.md)：投递 → 二维码已发，收到投递即回群二维码邮件。
- [进群检测](./group_entry.md)：二维码已发 / 无响应 → 已进群，轮询群名单，含七天超时与迟到追认。
- [问卷发放](./survey_dispatch.md)：已进群 → 问卷已发，入群后自动发准入问卷。

三条之后（已建清单起）执行者都是人或半自动，流程里不再有全自动段落。
