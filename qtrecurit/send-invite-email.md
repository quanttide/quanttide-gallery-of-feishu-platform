# 投递发码：从收件箱到群二维码邮件

本案例记录招聘流程的第一条管道：HR 邮箱收到投递邮件后，系统自动回一封带群二维码的邮件，候选人状态由「投递」进入「二维码已发」。全程无人参与。案例沉淀为六条意图规则、一份机器可读的迁移规格与一个通用执行器。

## 需求

### 情境

候选人把简历投到 `hr@quanttide.com`，公司通过飞书邮箱接收。系统要在收到投递后自动回一封带「量潮实训基地」群二维码的邮件，让人扫码进群——入口是收件箱里的一封投递邮件，出口是状态「二维码已发」。约束有四：全程无人参与；正文除二维码附件外还给一条群邀请链接；发送失败不得推进状态；同一份流程 YAML，Python 实验室与 Rust 执行器要跑出一致输出。

### 难点

难点有四：

- 投递识别不唯一：HR 处理邮件时会把投递移进「沟通面试中」等文件夹，只扫收件箱会漏；有效投递还可能被 Spam 误判，且 Spam 里的附件下载受限；
- 发信有前置：正文模板要嵌群邀请链接，链接必须在发信前先取；而实训基地群是外部群，机器人身份取不到链接，真取要用 HR 用户身份；
- 失败语义：动作要先做、失败就整轮报错——状态一旦与事实分叉，后面每一格都跟着错；
- 人工前置不可省：群二维码图片是真人放进附件目录的，机器不生成；

## 意图

### 自然语言规则

1. 收到即回：迁移不写检查，候选人进入「投递」格即无条件推；
2. 先取后发：发信前先取群邀请链接，按 `as` 起名，正文模板用 `{{邀请链接}}` 引用；
3. 动作先做：推格前先执行动作，失败整轮报错、状态不挪；
4. 状态可重建：进人以收件箱为准，状态可从飞书侧原始数据重建；
5. 人工前置最小：二维码图片由人放进附件目录，是本管道唯一人工前置；
6. 对照为证：以与实验室逐行相同的输出为成功判据，不以「跑通」为判据。

### 形式化规则

```text
对象：候选人 c（收件箱投递），流程 F，执行器 R

前置条件
  delivered(c) ∈ 收件箱 ∧ email(c) 合法
  群二维码图片 ∈ 附件目录
  可取群邀请链接 ∧ 可用 HR 用户身份

操作
  recognize(F, c)   从收件箱认出投递，登记为待发码的候选人
  prepare(F, c)     取一条群邀请链接
  send(F, c)        把链接写进正文，连同群二维码附件发给候选人
  record(F, c)      把候选人记为「二维码已发」，记下送达时间

不变式（发码后必须全部成立）
  I1 出口：状态(c) = 二维码已发
  I2 送达：正文含群邀请链接 ∧ 附群二维码图片
  I3 原子：任一步失败 ⇒ c 的状态与记录均不变
  I4 留痕：成功则记下送达时间
  I5 对照：输出与实验室参照逐行相同
```

## 规格

### 自然语言描述

管道分四步，每步以前一步的产出为输入，以可核对的结果收尾：

1. 认出投递：收件箱里新出现的投递，按发件人登记为待发码的候选人；结果＝同人重复投递只留一条，取最早日期。
2. 备邀请链接：为候选人取一条群邀请链接；结果＝拿到一条可点的链接。
3. 发邀请邮件：链接填进正文，连同群二维码附件发给候选人；结果＝邮件送达。
4. 记状态：候选人由「投递」变为「二维码已发」；结果＝状态更新、记下时间。

两条不论怎么实现都成立：任一步失败则本轮中止、候选人不前进；同一份流程定义，Python 与 Rust 两侧结果逐行相同。

### YAML 描述

机器可读的规格表示，与上面四步一一对应。

```yaml
收集:
  邮箱: hr@quanttide.com
  范围: [收件箱, 沟通面试中, Spam]     # 仅收件箱进人，其余是补拉留档范围

迁移:
  - 从: 投递
    到: 二维码已发
    触发: 收到投递，直接发群二维码
    执行者: 系统
    动作:
      能力: send_mail
      先取:
        - 能力: chat_link
          as: 邀请链接
      参数:
        to: "{{候选人.邮箱}}"
        subject: 量潮实训基地 · 群二维码
        body: |-
          你好，扫码直接进群（群二维码见附件）。
          也可以点这个链接进群：{{邀请链接}}
        attachments: [群二维码.png]
    副作用: 记发送时间
```

> 提示：范围里的「沟通面试中」「Spam」只用于补拉留档与人工核对，进人仍以收件箱为准。

## 实现

把这条管道拆到最原始，就是三条 `lark-cli` 调用——读收件箱、取群邀请链接、发邀请邮件：

```bash
MAILBOX=hr@quanttide.com
CHAT_ID=oc_实训基地群                  # 「量潮实训基地」群

# 1 认出投递：列收件箱摘要，发件人即候选人邮箱
lark-cli mail +triage --mailbox "$MAILBOX" --filter '{"folder":"收件箱"}' --format json

# 2 取群邀请链接（外部群机器人身份取不到，得用 HR 用户身份）
lark-cli im chats link --chat-id "$CHAT_ID" --as user --format json

# 3 发邀请邮件：链接填进正文，另附群二维码
lark-cli mail +send --mailbox "$MAILBOX" --to "$候选人邮箱" \
  --subject '量潮实训基地 · 群二维码' \
  --body '你好，扫码直接进群（群二维码见附件）。也可以点这个链接进群：{{邀请链接}}' \
  --attach 群二维码.png --confirm-send --as user
```

每个候选人重复第 3 步；执行器把这三步按流程串起来、管状态。案例执行结果：收件箱里的投递各收到一封带邀请链接与群二维码的邮件，候选人由「投递」记为「二维码已发」。
